Data

Last backup: never. Take one this week.

Chrome tip: Keep one VELKORE.html in a fixed folder (e.g. Documents/VELKORE). Do not open a new download each time. If Chrome says “file was edited or deleted”, close that tab and open the same file again from the folder — XP, sessions and timer recover from device storage.

Long sessions are saved while running. After hours away, reopen the same file — progress comes back.

File / tab recovery

Study data lives in this browser’s local storage, not only in the open tab. Raw file:// tabs can be discarded by Chrome after long idle; reopening the same HTML file reloads your data.
